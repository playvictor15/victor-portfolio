# João Victor — Portfólio Pessoal

Portfólio pessoal desenvolvido com HTML5, CSS3 e JavaScript puro.

## Tecnologias

- HTML5 semântico
- CSS3 com variáveis customizadas e design glassmorphism
- JavaScript vanilla
- Firebase Firestore (nos projetos)
- [Lucide Icons](https://lucide.dev/) v0.383.0
- Google Fonts — Inter

## Estrutura

```
victor-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Como rodar

Basta abrir o `index.html` no navegador. Nenhuma dependência de build necessária.

## Funcionalidades

- Design responsivo (mobile, tablet e desktop)
- Navbar com efeito de scroll e menu hambúrguer funcional
- Seções: Hero, Sobre, Projetos e Contato
- Acessibilidade: foco visível por teclado, `aria-expanded`, `aria-label`
- Desempenho: `preconnect` para Google Fonts, `passive` no listener de scroll
